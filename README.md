# bencepo.github.io

Web pages for Bencepo's World of Warcraft: Forever addons.

- [LevelTrail web viewer](https://bencepo.github.io/leveltrail/): paste the `/trail` export and see your leveling run.
- [VendorFloor profit page](https://bencepo.github.io/vendorfloor/): paste the VendorFloor export and see your profit per day, best items and time to sale.

Both pages run entirely in the browser; nothing is uploaded. The addons are on CurseForge: [LevelTrail](https://www.curseforge.com/wow/addons/leveltrail), [VendorFloor](https://www.curseforge.com/wow/addons/vendorfloor), [SwingCast](https://www.curseforge.com/wow/addons/swingcast), [StatTrim](https://www.curseforge.com/wow/addons/stattrim) ([demo](media/stattrim/demo.gif)).
